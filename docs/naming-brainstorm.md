# 命名头脑风暴记录

## 核心元素

| 维度 | 关键词 |
|------|--------|
| **注意力** | Attention, Focus, Awareness, Mindfulness |
| **问题** | Problem, Issue, Challenge, Question |
| **驱动** | Driven, Guided, Led, Oriented |
| **决策** | Decision, Choice, Judgment, Call |
| **框架** | Framework, Toolkit, Model, Method |
| **生命周期** | Lifecycle, Journey, Flow, Cycle |

## 候选命名

### 方案 A: 保留 APT（Attention Problem Toolkit）
- **优点**: 简洁，3 字母易记，与问题空间控制强关联
- **缺点**: 与 "Advanced Package Tool" 冲突，可能混淆
- **变体**: APF (Attention Problem Framework), APD (Attention Problem Driven)

### 方案 B: 问题生命周期导向
- **PDLF** (Problem-Driven Lifecycle Framework) — 强调生命周期
- **PDDF** (Problem-Driven Decision Framework) — 强调决策
- **PLAT** (Problem Lifecycle Attention Toolkit) — 生命周期 + 注意力

### 方案 C: 注意力导向
- **AFTP** (Attention Follows The Problem) — 直接引用核心原则
- **AFPF** (Attention-Focused Problem Framework) — 注意力聚焦
- **Mindful Engineering** — 偏哲学，不够技术

### 方案 D: 中文优先
- **问注框架** — 问题 + 注意力，简洁但生造词
- **随问而动** — 诗意，不够工程
- **问题生命周期框架 (PLCF)** — 直白，但长

## 推荐

**主名**: **PDLF** (Problem-Driven Lifecycle Framework)
- 准确描述: 问题驱动 + 生命周期 + 框架
- 无冲突，搜索友好
- 可扩展: PDLF-Toolkit, PDLF-Model

**副名/口号**: Attention Follows the Problem
- 保留核心哲学
- 作为标语而非技术名

**中文名**: **问题驱动生命周期框架**
- 直白，无歧义
- 适合技术文档和演示
