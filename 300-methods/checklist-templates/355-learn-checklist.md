# Learn 检查清单

> **不是归档，是沉淀。不是存储，是学习。**

---

## 沉淀维度

### 1. 问题模式提取

- [ ] 这个问题的**根因**是什么？
- [ ] 这个根因是否代表了**一类问题**？
- [ ] 这类问题的**触发条件**是什么？
- [ ] 这类问题的**早期信号**是什么？（下次如何更早发现？）

### 2. 解决方案沉淀

- [ ] 最终解决方案是什么？
- [ ] 为什么选这个方案？（决策记录）
- [ ] 这个方案是否**可复用**？（其他场景是否适用？）
- [ ] 这个方案的**边界条件**是什么？（什么情况下不适用？）

### 3. 检测方法沉淀

- [ ] 如何在问题**发生前**检测？（Prevent）
- [ ] 如何在问题**发生时**检测？（Detect）
- [ ] 如何在问题**发生后**恢复？（Recover）

### 4. 知识传播

- [ ] 这个知识应该**分享给谁**？
- [ ] 以什么**形式**分享？（文档 / 分享会 / 检查清单）
- [ ] 是否需要更新**团队规范**？（代码规范 / CR 清单 / 测试策略）

## 知识沉淀模板

```markdown
## Learn

### 问题模式
- 模式名称: 函数包裹索引列导致索引失效
- 触发条件: ORM 自动生成 DATE(column) 查询
- 早期信号: 查询计划显示全表扫描

### 解决方案
- 方案: 改写查询为范围查询
- 决策原因: 零风险、立即生效、不依赖 DB 变更
- 可复用场景: 所有函数包裹索引列的查询
- 边界条件: 时间范围查询替代函数查询

### 检测方法
- Prevent: CR 检查清单增加"索引列函数包裹"项
- Detect: CI 自动 EXPLAIN，标记全表扫描
- Recover: 查询熔断，超时降级

### 知识传播
- 分享对象: 全团队
- 形式: 技术分享 + 检查清单更新
- 规范更新: 代码审查清单 v2.1

### 风险录入
- 已录入 risk.md: ✅
- RPN: 192
- 监控状态: 已部署慢查询告警
```

## 组织学习能力评估

| 能力 | 低级 | 中级 | 高级 |
|------|------|------|------|
| **模式识别** | 每次从零开始 | 能识别相似问题 | 能提前预警系统性风险 |
| **知识复用** | 知识只存在个人脑中 | 有文档但没人看 | 知识自动匹配到新问题 |
| **预防能力** | 问题发生后修复 | 问题发生时检测 | 问题发生前预防 |
| **传播效率** | 口口相传 | 有文档 | 检查清单自动集成到流程 |
