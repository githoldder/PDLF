# Decisions

## 2026-10-01: 选择改写查询而非加函数索引

**背景**: 根因已定位——`DATE(created_at)` 导致索引失效

**选项A**: 加函数索引
- 优点: 不改代码，对现有查询透明
- 缺点: 需要 DB 变更，回滚慢；不是所有数据库都支持函数索引；增加维护成本

**选项B**: 改写查询为范围查询
- 优点: 零风险，立即生效，兼容所有环境，代码层面可控
- 缺点: 需要改代码，需测试所有调用点

**选择**: B

**原因**:
1. 风险最低——代码回滚比 DB 回滚快得多
2. 能立即验证效果——改完就能 EXPLAIN
3. 更符合团队能力——开发者对代码比 DB 更熟悉

**结果**: 5 分钟修复，P99 从 3200ms → 95ms
