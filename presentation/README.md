# PDLF reveal.js presentation

This folder contains a reveal.js presentation for PDLF.

## Run locally

From the repository root:

```bash
python3 -m http.server 5173
```

Then open:

```text
http://127.0.0.1:5173/presentation/
```

## Files

- `index.html`: the reveal.js deck
- `styles.css`: presentation styling
- `script.js`: small interaction for the attention budget slide
- `research.md`: presentation technique and reveal.js research notes

## Speaker controls

- Use the arrow keys to move through slides.
- Press `S` to open speaker notes.
- Press `F` for fullscreen.
- Press `Esc` for overview mode.
